#   pip install -r requirements-dev.txt
#
# Why a separate file: `pyproject.toml` takes the project's dependencies from

# *published* dependency list. This file adds the editable install of the CLI and its test
# extras on top.
#
# Never add a local path to either file: requirements.txt would carry it into the published
# metadata and break every consumer of the released package.
# nuvel-mcp will come from PyPI once it is published there; until then the release is its git tag (no PyPI credential yet).
